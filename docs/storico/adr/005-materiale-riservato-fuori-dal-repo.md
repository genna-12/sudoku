# ADR 005 — Materiale personale fuori dal repo pubblico
- Data: 2026-11-04
- Stato: accettato
- Ricerche: nessuna
- Collegati: nessuno

## Decisione
Il repo `genna-12/sudoku` è pubblico (GitHub Pages). Le parole testuali di Genna sulle difficoltà della coppia non entrano nel repo: stanno nel documento privato del Project Claude `claude/storia-materiale-riservato.md`. Nel repo i temi compaiono solo in forma neutra (bibbia §6, verbale). I capitoli della storia, che sono fatti per essere letti da Mati, restano nel repo.

## Cosa la farebbe cambiare
Repo reso privato: il materiale potrebbe tornare nel verbale. Finché è pubblico, no.
